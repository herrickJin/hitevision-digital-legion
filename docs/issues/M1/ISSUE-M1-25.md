# ISSUE-M1-25: 审核人界面

## Parent
PRD-101 §4.5, §4.6

## What to build
实现审核人界面：1.待审核列表 2.审核详情页（原型配置+测试报告+配置快照+历史版本） 3.通过操作 4.驳回操作（必填驳回原因） 5.通过后自动上架。遵循 PRD-100 §12.1.3 危险操作确认模板。

## Acceptance criteria
- 审核详情展示完整配置和测试报告
- 驳回原因必填
- 通过后自动触发状态转换到已上架
- 操作使用二次确认弹窗

## Blocked by
- ISSUE-M1-24（HITL — 需产品确认审核流程）
