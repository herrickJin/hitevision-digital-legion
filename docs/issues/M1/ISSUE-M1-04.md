# ISSUE-M1-04: 原型详情页（配置总览/状态/版本历史）

## Parent
PRD-101 §4, PRD-100 §12 设计要求

## What to build
实现 Soul Prototype 详情页前端，展示：
1. 基础信息区（名称/角色/状态/版本/负责人/风险等级）
2. 配置总览区（人格/职责/输出/约束/能力/知识，按配置完整度展示）
3. 状态与操作区（根据当前状态显示可执行操作，遵循 ISSUE-M0-08 状态机）
4. 版本历史区（版本列表 + 版本号 + 变更说明 + 变更时间）
5. 四种 UI 状态覆盖

## Acceptance criteria
- 详情页展示原型全部配置信息
- 状态相关操作按钮与 ISSUE-M0-08 状态机一致
- 版本历史可查看历史配置
- 覆盖四种 UI 状态
- 未配置区域有引导提示

## Blocked by
- ISSUE-M1-01（CRUD API）
- ISSUE-M1-02（快照存储）
- ISSUE-M0-08（状态机规格）
- ISSUE-M0-18（UI 状态规范）
