# ISSUE-M1-26: 上架/下架/归档操作

## Parent
PRD-101 §4.5

## What to build
实现上架/下架/归档操作：1.上架（审核通过后自动） 2.下架（核心管理员主动/系统强制，触发 ISSUE-M0-13 联动约束） 3.归档（核心管理员操作） 4.操作确认弹窗（遵循 PRD-100 §12.1.3 下架确认模板）。

## Acceptance criteria
- 下架触发 ISSUE-M0-13 定义的实例回收流程
- 归档不可逆
- 所有操作使用二次确认弹窗
- 操作记录写入审计日志

## Blocked by
- ISSUE-M1-21, ISSUE-M0-13
