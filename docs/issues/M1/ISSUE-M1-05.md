# ISSUE-M1-05: 新建向导框架（分步导航 + 草稿保存）

## Parent
PRD-101 §4, PRD-100 §5 设计要求 1

## What to build
实现原型新建向导的分步导航框架：1.分步进度条展示当前步骤 2.步骤间前进/后退导航 3.草稿自动保存（每步变更触发） 4.草稿恢复（重新进入时加载） 5.步骤完成度指示 6.最终提交前的完整配置预览。步骤顺序：基础信息→人格定义→职责范围→输出规范→安全约束→能力绑定→知识配置。

## Acceptance criteria
- 分步导航流畅无阻断
- 草稿自动保存频率合理（debounce）
- 草稿恢复无数据丢失
- 步骤完成度指示准确
- 最终预览覆盖全部配置项
