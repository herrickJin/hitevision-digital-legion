# ISSUE-M1-27: 审计日志记录

## Parent
PRD-100 §11.2, PRD-101 §9 验收标准 4

## What to build
实现原型全生命周期审计日志：1.创建/编辑/提交测试/测试通过/提交审核/审核通过/审核驳回/上架/下架/归档 全部动作记录 2.审计日志写入 Audit Log（ISSUE-M0-05） 3.审计日志查询 API 4.审核人/管理员可查看审计记录。

## Acceptance criteria
- 所有关键状态变更写入审计日志
- 审计记录包含操作人/操作时间/操作类型/变更前后状态
- 审计日志不可修改
- 审核人可在详情页查看审计历史
