# ISSUE-M1-24: 提交审核（附测试报告 + 配置快照）

## Parent
PRD-101 §4.5, §4.6

## What to build
实现提交审核流程：1.提交前强制校验（完整性+测试通过） 2.自动附加最新测试报告 3.自动创建配置快照 4.触发状态转换（草稿/已驳回→待测试→测试中→待审核） 5.提交通知审核人。

## Acceptance criteria
- 未通过校验的原型无法提交
- 提交时自动附加测试报告和配置快照
- 状态转换链自动执行
- 审核人收到提交通知
