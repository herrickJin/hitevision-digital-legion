# ISSUE-M1-03: 原型列表页（搜索/筛选/分页/排序）

## Parent
PRD-101 §4.1, PRD-100 §11.1 性能要求

## What to build
实现 Soul Prototype 列表页前端，支持：
1. 原型列表展示（卡片/列表视图切换）
2. 关键字搜索（名称、角色）
3. 筛选（角色类型、状态、风险等级、负责人）
4. 分页（遵循 ISSUE-M0-16 分页规范）
5. 排序（更新时间、创建时间、名称）
6. 四种 UI 状态（加载中/空状态/失败/禁用，遵循 ISSUE-M0-18）
7. 空状态引导（"创建第一个数字员工原型"）

## Acceptance criteria
- 列表加载 P95 ≤ 2 秒（PRD-100 §11.1）
- 搜索结果返回 P95 ≤ 3 秒
- 筛选条件可组合使用
- 覆盖四种 UI 状态
- 空状态有引导操作按钮

## Blocked by
- ISSUE-M1-01（CRUD API）
- ISSUE-M0-18（UI 状态规范）
