# ISSUE-M0-01: Project 对象 P0 字段定义

## Parent
PRD-100 §5.3, §13.2.4

## What to build
定义 Project 对象的 P0 字段规范：字段名、类型、必填性、约束和索引建议。覆盖项目名称、Owner、目标、成员列表与角色、配额、实例池、Wiki 绑定、Project Memory、项目状态。

## Acceptance criteria
- 覆盖 PRD-100 §5.3 P0 属性清单全部字段
- 每个字段有明确的类型、必填性、约束说明
- 枚举类型列出完整值域
- 给出至少 3 个核心查询场景的索引建议

## Blocked by
None — 可立即开始
