## 1. 核心术语定义

| 统一术语 | 英文标识 | 定义 |
|---------|---------|------|
| **Soul 原型** | Soul Prototype | 包含人格定义、职责范围、能力集、输出规范、安全约束、初始记忆等完整配置的数字员工定义。是 PRD-001-Soul可视化编排与数字员工原型管理-v1.0.md 的核心产出。 |
| **数字员工实例** | Agent Instance | 用户订阅并派发到运行环境的数字员工运行体。由 Soul 原型实例化而来，拥有独立的运行状态、用户数据和上下文。是 PRD-002-数字员工市场-v1.0.md 的核心管理对象。 |
| **Issue** | Issue / Task Issue | 数字员工任务协作的唯一载体。用户通过 Issue 向数字员工实例下发任务、跟踪执行、接收结果。是 PRD-003-Issue任务执行与交互-v1.0.md 的核心对象。 |
| **Body** | Body | 能运行的通用智能体空壳（如 Hermes Agent），Soul 原型绑定到 Body 上形成可运行的数字员工。 |
| **核心管理员** | Platform Admin | 拥有全部管理权限的平台管理员。负责 Soul 原型全生命周期管理、Body 管理、能力注册、业务域授权等。 |
| **授权创作者** | Authorized Creator | 被核心管理员授权到特定业务域的 Soul 原型创建者。可在授权范围内创建、编辑、测试、提交审核 Soul 原型。 |
| **审核人** | Reviewer | 由核心管理员和授权创作者组成，对待审核 Soul 原型进行通过或驳回。 |
| **订阅用户** | Subscriber | 通过市场订阅并派发数字员工实例的产研用户。是数字员工的使用者。 |

## 3. 使用规则

1. **新文档优先使用统一术语**：后续新增 PRD 或设计文档应使用本表定义的统一术语。
2. **存量文档不做全量替换**：PRD-001-Soul可视化编排与数字员工原型管理-v1.0.md、PRD-002-数字员工市场-v1.0.md、PRD-003-Issue任务执行与交互-v1.0.md 保持原有术语，通过本映射表消除歧义。
3. **术语冲突时以本表为准**：当不同 PRD 对同一概念使用不同名称时，以本表的统一术语为标准定义。
4. **新增术语需更新本表**：后续 PRD 新增核心术语时，必须同步更新本映射表。
