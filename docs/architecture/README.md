## 约定

- 每个 ADR 遵循统一格式：上下文、决策、被拒绝的替代方案、后果、复审条件
- 状态流转：提议 → 已确认 → 已废弃 / 已替代
- 决策一旦进入"已确认"，只能被新 ADR 替代，不直接修改
